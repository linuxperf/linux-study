# 第 0 章 前言

阅读内核源码的目标不是记住函数名，而是能回答：一个请求经过哪些层次，状态由谁维护，哪些条件允许它继续执行，以及如何在运行中的系统里验证判断。本章建立全书共用的阅读方法、构建边界和验证流程，不提前展开各子系统的完整实现。

本书的分析基线为仓库中的 Linux v6.18.60、x86_64 和 [`linux/.config`](../../linux/.config)。版本号来自 [`Makefile:2-5`](../../linux/Makefile#L2-L5)，不是根据虚拟机的发行版名称推断。实验得到的结论还必须注明实际运行的内核、配置、工具和工作负载。

## 本章目标

读完本章，应能完成以下工作：

1. 区分源码事实、配置条件、运行时选择和实验现象。
2. 在不修改仓库 `linux/` 的前提下准备构建副本与索引。
3. 沿“入口 → 数据结构 → 状态变化 → 退出路径”阅读代码，并识别架构与配置分支。
4. 完成一次有准备、有采集、有清理的跟踪实验，知道空结果与丢失事件各意味着什么。

## 阅读路线

- 首次阅读：按 0.1～0.4 顺序完成准备，再进入 [第 1 章 启动过程](../01-boot/README.md)。暂时不能构建内核时，也可以先阅读源码；不要把缺少索引当成无法阅读的理由。
- 带问题查阅：先读目标章的导读与概述，确认前置知识，再用 0.3 的导航流程追踪实现，用 0.4 的方法验证。
- 只做工具练习：可以使用虚拟机的发行版内核，但必须记录版本，并把结果标为工具练习，不能据此宣称已经验证 v6.18.60。
- 涉及睡眠、抢占、锁和中断的代码，可交叉阅读 [第 7 章 同步与锁](../07-sync/README.md)；本章不要求预先掌握这些实现。

## 环境与安全边界

| 对象 | 本章约定 |
|---|---|
| 仓库 `linux/` | 只读分析基线；不构建、不清理、不写入索引或编辑器配置 |
| 仓库根目录 `.config` | 只有两条证书相关记录，不是完整内核配置；基线使用 `linux/.config` |
| 虚拟机 | 由 [`dev/Vagrantfile`](../../dev/Vagrantfile) 声明；默认启动内核不保证与本书一致 |
| 构建与索引 | 在虚拟机本地磁盘的仓库外源码副本和独立输出目录中完成 |
| 安装与重启 | 不是阅读源码的前提；必须另行确认快照、控制台和旧内核回退能力 |
| 跟踪实验 | 只在可恢复的实验机执行，使用独立 tracefs 实例，结束后关闭并删除实例 |

根目录 [`Makefile:1-4`](../../Makefile#L1-L4) 的 `make clangd` 会在 `linux/` 中执行配置、构建和数据库生成，不满足这里的只读约定。本章只说明替代流程，不修改该目标。
